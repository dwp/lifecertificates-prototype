This page shows how the support agent service works in version {{ version.number }}.

User needs

  1. As a support agent, I need to review submitted life certificates, so that I can decide whether pension payments should continue.
  2. As a support agent, I need to review customer information and evidence, so that I can understand and resolve cases.

Simplified journey flow

Case management

  1. Open dashboard
  2. Select a case
  3. Review case overview
  4. Review customer information, evidence, notes or timeline
  5. Add case notes if required

Life certificate review

  1. Open life certificate
  2. Review OCR-captured information
  3. Review identified differences
  4. Record review decisions
  5. Complete review and return to case
