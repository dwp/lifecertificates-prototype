Phone input

Collect telephone numbers using separate country code and national number inputs.

{{ appPhoneInput({ id: "phone-number-example", namePrefix: "phone-number-example", fieldset: { legend: { text: "What is your phone number?", isPageHeading: true, classes: "govuk-fieldset__legend--l" } }, hint: { text: "Include the country code and phone number. When to use this

  • when users may provide international telephone numbers
  • when country codes need to be stored separately
  • when a service is used by customers in multiple countries
  • when country codes and national numbers need different validation rules

When not to use this

  • when a phone number is not required
  • when another contact method is more appropriate
  • when telephone details are supplied from another trusted source
{{ govukInsetText({ text: "Hide the country code input when users only need to provide a national phone number." }) }}

How it works

The component provides separate inputs for the country code and national phone number. This avoids forcing services to split phone numbers after submission and makes it easier to validate and store both values independently.

If you're collecting an international phone number

Use the country code input when users may provide phone numbers from different countries or when the country code needs to be stored separately.

Validation and error handling

Validation should be performed by the page or service using the component. The component displays any supplied error state and error messaging using standard GOV.UK patterns.
