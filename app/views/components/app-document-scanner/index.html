Components and patterns

Document scanner

Capture an image of a document using a device camera.

The document scanner is a reusable component used within a page-level pattern. The component handles the camera preview, document guide, image capture, cropping behaviour and hidden input.

The page pattern should handle the heading, error summary, form, fallback route and journey content.

When to use this

  • capturing identity documents
  • capturing passports, driving licences or residence permits
  • capturing evidence documents using a device camera
  • guiding users to position documents consistently

When not to use this

Do not use this as the only way for users to provide a document.

  • when users need to upload an existing file
  • when camera access is optional
  • when a standard file upload is more appropriate
  • when users may not have access to a working camera
{{ govukInsetText({ text: "Always provide an alternative document upload route if camera access is unavailable." }) }}

Using the document scanner pattern

The recommended pattern is to render the error summary before the page heading, render the form in the page, and pass the form ID and error summary ID into the document scanner.

This keeps the GOV.UK page structure correct while allowing the component JavaScript to update the error summary if camera access fails.

JavaScript API

Each document scanner instance is registered on window.documentScanners. 

var scanner =
  window.documentScanners['identity-document-front']

Capture an image

scanner.capture()

Get the current image

scanner.getImage()

Clear the image

scanner.clear()

Update detection state

scanner.setDetected(true)

Events

document-scanner:capture

Fired after an image is captured. 

document.addEventListener(
  'document-scanner:capture',
  function (event) {
    console.log(event.detail)
  }
)

document-scanner:clear

Fired when the stored image is cleared. 

document.addEventListener(
  'document-scanner:clear',
  function (event) {
    console.log(event.detail)
  }
)

document-scanner:resize

Fired when the document guide geometry changes. 

document.addEventListener(
  'document-scanner:resize',
  function (event) {
    console.log(event.detail.guide)
  }
)

Accessibility

  • uses a live region for status updates
  • supports keyboard form submission
  • can update an external GOV.UK Error Summary
  • does not rely only on the visual document frame to explain the task
  • supports configurable guidance before the camera is ready

Error handling

Camera errors are shown in the GOV.UK Error Summary when an errorSummaryId is supplied. If no external error summary is supplied, the component renders a fallback error summary inside the component.
