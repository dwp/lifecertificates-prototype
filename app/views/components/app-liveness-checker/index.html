Components and patterns

Liveness checker

Capture a photo of a person using a device camera and guide them to position their face inside an oval frame.

The liveness checker is a reusable component used within a page-level pattern. The component handles the camera preview, oval guide, capture behaviour and hidden input.

The page pattern should handle the heading, error summary, form, fallback route and journey content.

When to use this

  • checking that a person is present during an identity journey
  • capturing a face image to compare with an identity document
  • guiding users to position their face consistently
  • taking a selfie-style image using a front-facing camera

When not to use this

Do not use this as the only way for users to complete a task.

  • when users only need to upload an existing image
  • when camera access is optional
  • when the service does not need a face image
  • when users may not have access to a working camera
{{ govukInsetText({ text: "Always provide an alternative route for users who cannot use their camera or cannot verify their identity this way." }) }}

Using the liveness checker pattern

The recommended pattern is to render the error summary before the page heading, render the form in the page, and pass the form ID and error summary ID into the liveness checker.

This keeps the GOV.UK page structure correct while allowing the component JavaScript to update the error summary if camera access fails.

JavaScript API

Each liveness checker instance is registered on window.livenessCheckers. 

var checker =
  window.livenessCheckers['liveness-check']

Capture an image

checker.capture()

Get the current image

checker.getImage()

Clear the current image

checker.clear()

Set detection state

checker.setDetected(true)

Events

liveness-checker:capture

Fired after an image is captured. 

document.addEventListener(
  'liveness-checker:capture',
  function (event) {
    console.log(event.detail)
  }
)

liveness-checker:clear

Fired when the stored image is cleared. 

document.addEventListener(
  'liveness-checker:clear',
  function (event) {
    console.log(event.detail)
  }
)

liveness-checker:resize

Fired when the oval guide geometry changes. 

document.addEventListener(
  'liveness-checker:resize',
  function (event) {
    console.log(event.detail.guide)
  }
)

Accessibility

  • uses a live region for status updates
  • supports keyboard form submission
  • can update an external GOV.UK Error Summary
  • does not rely only on the visual oval to explain the task

Error handling

Camera errors are shown in the GOV.UK Error Summary when an errorSummaryId is supplied. If no external error summary is supplied, the component renders a fallback error summary inside the component.
